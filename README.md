# Make Fetch Happen app

A mobile web app for [Make Fetch Happen Dog Training](https://www.makefetchhappen.co.uk), South Manchester.

- Booking requests sent to Janey by WhatsApp
- QR code scanner and generator, including homework cards
- Daily training log with streaks
- Services, about and contact pages

A single static `index.html`, hosted on GitHub Pages. No build step.
